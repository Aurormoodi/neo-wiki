# NEO Wiki

Eigenständiges, responsives Nachschlagewerk für NEO mit Suche, Kategorien und verknüpften Artikeln.

## Dateien
- `index.html` – Seitenstruktur
- `style.css` – dunkles NEO-Design
- `script.js` – Artikeldaten, Suche, Filter und Artikeldialoge
- `articles/` – für zukünftige ausgelagerte Artikeldaten
- `assets/` – für freigegebene Logos und Medien

## Lokal testen
`index.html` im Browser öffnen. Es werden keine externen Bibliotheken benötigt.

## GitHub hochladen
1. Repository `neo-wiki` öffnen.
2. **Add file → Upload files** wählen.
3. `index.html`, `style.css`, `script.js`, `README.md` sowie die Ordner `articles` und `assets` hochladen.
4. Änderungen committen.
5. **Settings → Pages → Deploy from a branch**, Branch `main`, Ordner `/ (root)` wählen und speichern.
6. Die Seite sollte unter `https://DEIN-BENUTZERNAME.github.io/neo-wiki/` erreichbar sein.
